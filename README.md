# Ragebot: реконструкция в читаемый C

**Конечная цель — полный связный Ragebot исходного проекта на читаемом C,
вместе с транзитивно необходимыми ему частями. Цель ещё не достигнута.**
Сейчас реализованы шесть ограниченных офлайн-модулей на **C++17** с тестами
и байтовыми основаниями. Это база для дальнейшей реконструкции, а не готовый
Ragebot, не полный перенос на C и не доказанная эквивалентность оригиналу.

## Начать новому агенту

1. Прочитать [AGENTS.md](AGENTS.md) и [цель/критерии готовности](docs/GOAL.md).
2. Посмотреть [карту материалов и текущее состояние](docs/SOURCE_INDEX.md),
   затем [STATUS.json](continuation/STATUS.json).
3. Восстановить материалы и проверить базу по [BOOTSTRAP.md](docs/BOOTSTRAP.md).
   Все шесть исходных частей уже находятся в Git; вложения из чата не нужны.
4. Выбрать **одну ограниченную задачу** из [плана](docs/ROADMAP.md)
   и [реестра заданий](docs/TASKS.json), согласовав владельца с координатором.
5. Работать по [протоколу нескольких агентов](docs/AGENT_WORKFLOW.md).
   [Готовые промпты](docs/AGENT_PROMPTS.md) можно передать агенту любого поставщика.

## Что хранится где

| Путь | Назначение |
|---|---|
| `docs/` | Актуальная общая цель, дорожная карта, запуск и передача работы |
| `continuation/` | Реальный текущий C++17-код, тесты, локальные контракты и доказательства |
| `RAGEBOT_V10_часть_01_из_06.zip` … `06_из_06.zip` | Шесть ZIP-обёрток фрагментов исходного комплекта, не шесть отдельных наборов |
| `runs/handoff/RAGEBOT_HANDOFF_V10/` | Локально восстановленные материалы; не коммитить повторно |
| `PROMPT_ДЛЯ_АГЕНТА_ЧАСТИ.txt` | Неизменённый исторический запрос; текущая цель и организация уточнены в `docs/` |
