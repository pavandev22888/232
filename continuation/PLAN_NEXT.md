# План следующих волн

> Исторический план завершённых W3–W4. Актуальная общая цель и следующие
> назначения: [ROADMAP](../docs/ROADMAP.md) и [TASKS](../docs/TASKS.json).

Дата: 2026-11-09. Принятая база: `d0500c5` (6528 C++ assertions на режим).
Ответы пользователя: **баланс**, **несколько волн**, **PR без слияния**.
Модель агентов — `gpt-6.1-sol`; effort/fast недоступны в интерфейсе запуска.

## Цель и остановка

За два ограниченных прохода соединить доказанные scalar-контракты с моделью N,
исследовать одну конкретную неизвестную зависимость и проверить интеграцию
другими агентами. Не обещать полную реконструкцию и не повторять отклонённые
CODE01/GAP02 реализации. Остановка — после приёмки, общего `make check`,
проверки input integrity, commit/push и обновления PR; при отсутствии нового
доказательства фиксировать границу, а не начинать бесконечный поиск.

## Волна 3 — отдельные worktree и коммиты

Каждый worktree создаётся от одного коммита с этим планом и спецификацией.
У него отдельная ветка, Git index, исходники и build. Общий handoff используется
только на чтение через абсолютный `--handoff`; исходные файлы не копируются в Git.
Агенты не меняют родительскую ветку, не push, не merge/cherry-pick чужие коммиты.

| ID | Задача | Разрешённая запись |
|---|---|---|
| W3-M | Композиция scalar-helper для N+50/+54 с существующим marker producer | новые `marker_pipeline.hpp/.cpp`, `test_marker_pipeline.cpp`, `evidence/wave3/marker/` |
| W3-A | Разрешение трёх компонентов позиции через тот же helper с независимыми наблюдениями | новые `actor_scalar_pipeline.hpp/.cpp`, `test_actor_scalar_pipeline.cpp`, `evidence/wave3/actor/` |
| W3-S | Одна новая проверяемая цепочка N+14: источник или точная граница alias/source | только `evidence/wave3/source/` |
| W3-V | Проверка воспроизводимости baseline в отдельном worktree, переносимость HANDOFF, границы запуска | только `evidence/wave3/repro/`; конкретные ошибки сообщить координатору |

W3-M/W3-A продвигают GAP04/GAP05, W3-S — provenance, W3-V — GAP06.
GAP01, GAP03 и широкие CODE01/GAP02 остаются в общем остатке без ложного закрытия.
Каждый агент обязан проверить рабочий каталог/ветку, выполнить узкие тесты,
создать один коммит только своих файлов и вернуть SHA плюс точные результаты.

## Волна 4 — независимая приёмка интегрированной версии

1. Координатор просматривает diff, доказательства и результаты каждого агента.
2. Принимает подходящие коммиты в текущую ветку через `cherry-pick`.
3. Создаёт новые worktree от интегрированного SHA для двух рецензентов:
   один сверяет обе композиции с байтовыми call-sites и предпосылками,
   второй повторяет сборку/санитайзеры и проверяет тестовые сценарии отказов.
4. Исправления — только по конкретным находкам; расширение scope требует
   отдельного плана. Рецензенты не правят общие файлы одновременно.
5. Общий `make -C continuation check`, hashes исходников, input integrity,
   актуальные STATUS/README, commit, explicit-refspec push, PR без merge.

## Публикация и ограничения

- Уже сделанные коммиты отправляются в `hoplite/sikyon-46eee495`.
- Рабочие ветки агентов локальные; принятые изменения публикуются в общей ветке.
- Исходные архивы/DLL, attachments, build и временные каталоги не публикуются.
- PR создаётся к `main`, автоматическое слияние отключается; merge не выполняется.
- Не разрешены загрузка/исполнение/эмуляция исходных DLL, игровые подключения,
  injection, догадки вместо внешних наблюдений и модификация handoff/input/work.
- Исторический PASS не новый PASS; модельный rollback не свойство оригинала.

Результаты и worktree/commit ledger будут в `evidence/wave3/verification.json`
и `evidence/wave4/`; текущие требования — в `SPEC_NEXT.md`.
