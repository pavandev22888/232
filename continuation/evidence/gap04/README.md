# GAP04 — внешний адрес и граница привязки

Этот узкий статический прогон подтверждает локальную цепочку вычисления
`0x289A6D60` и сравнивает три клиентских адреса-кандидата. Он не назначает
внешнему адресу модуль или runtime-base. Скрипт читает файлы как данные;
DLL не загружаются и не исполняются.

## Повторение

Из корня репозитория:

```sh
python3 continuation/evidence/gap04/check_bindings.py
```

Для другого восстановленного комплекта:

```sh
python3 continuation/evidence/gap04/check_bindings.py --handoff /absolute/path/RAGEBOT_HANDOFF_V10
```

Зависимости — только стандартная библиотека Python 3. Скрипт не пишет файлы.

## Вывод

- В `nl.bin` по `0x414F3E19..0x414F3E5A` байты образуют 32-битное преобразование
  константы в `0x289A6D60`, затем сохраняют и вызывают значение через `call eax`.
  Это доказывает статически закодированный путь вызова, но не его выполнение.
- В PE32 `client.dll` `0x10876D60` — адрес с обычным прологом и содержимым,
  согласующимся с capsule-кандидатом V6; `0x103E6D60` находится в кодовом блоке
  с обратной ветвью к `0x103E6BC7`, без доказательства отдельного входа.
  `0x10076D60` — короткая обёртка с вызовом `0x108A6380`.
- Все 16 записей V6 имеют совпадающие байты в соответствующем PE и дают
  `0x289A6D60` только при своих разных `runtime_base_hypothesis`. Эти базы не
  наблюдались. Поэтому адрес `0x10876D60` структурно сильнее, но не является
  доказанной runtime-привязкой; выбор между ним и альтернативами остаётся
  открытым без независимого факта о загруженном модуле.
- Отдельные инвентари V5 (14 неоднозначных сигнатур) и V6 (16 внешних
  требований) остаются нерешёнными. Их строки не превращены в закрытые
  зависимости.

## Предпосылки и пределы

`0x412A0000` — только условная база адресации raw `nl.bin` из существующей
карты доказательств. Для PE используются проверенные `ImageBase` и таблицы
секций. Совпадение байтов и структурная похожесть не доказывают runtime-base,
принадлежность модуля, тип полного интерфейса, достижимость или семантику
остальных ветвей. Сырые совпадения чисел, похожие адреса и первый результат
поиска сигнатуры не используются как привязка.
