# GAP06 — ограниченный аудит и повтор H01

Субагент проверил исходный `position_records` по выбранным V10 walks и не
сообщил конкретных расхождений. Это source review первого модуля, не аудит
новых `charge_state`/`position_lifecycle`, не внешний независимый аудит и не
доказательство эквивалентности оригиналу. Проверенные версии исходников,
тестов, walks и исторических материалов закреплены SHA-256 в проверщике.

```sh
python3 continuation/evidence/gap06/verify_h01_replay.py \
  --handoff runs/handoff/RAGEBOT_HANDOFF_V10
make -C continuation check
```

Первую команду координатор выполнил повторно: подтверждены хеши, выбранные
байты, отображение PE-адресов в файловые смещения и свежие декодирования GNU
objdump для **162** записей: 143 resource и 19 client. Образы читаются как данные.

`h01_byte_replay.json` — сохранённый исторический снимок, а не новый журнал
исполнения. Проверщик сверяет его с архивом и заново проверяет указанные байты;
свежий общий результат находится в `../parallel_verification.json` и `.log`.

Архив сообщает 209 успешных H01-проверок. Из них **47 не воспроизведены**
этим проверщиком; строгий старый протокол не повторён, его скрипт по реестру
отсутствует. Сохранённый исторический PASS не превращён в новый PASS.
Прежний прогон 2 601 assertions относится только к первому модулю; текущая
интегрированная проверка трёх модулей учитывается отдельно.
