# W7: локальная связь caller → callback

Свежие байты связывают `0x414A8D68` с `0x4149E790`: ECX передаёт адрес
контекста, EDX — адрес точки. Пролог и обычный эпилог фиксируют scratch,
сохраняемые регистры и bare RET. [Контракт](contract.json) намеренно не
присваивает этой связи исходный calling-convention keyword или C++-тип.

Первое назначение исполнителю не дало evidence/коммита/тестов. Координатор
выполнил только описанную локальную проверку; это не доказательство
неразрешимости исходников. W5 RTTI-marker не соединён с данным callback.
Исходный язык/стандарт и полный ABI остаются unknown.

```sh
python3 -B continuation/evidence/wave7/abi/verify_source_bytes.py --handoff "$HANDOFF"
```
