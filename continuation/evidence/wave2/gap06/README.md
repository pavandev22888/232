# Ограниченный повтор оставшихся H01

```sh
python3 -B continuation/evidence/wave2/gap06/verify_remaining_h01.py \
  --handoff runs/handoff/RAGEBOT_HANDOFF_V10 \
  > runs/wave2/gap06/recheck.json
python3 -B -m unittest discover \
  -s continuation/evidence/wave2/gap06 -p 'test_*.py' -v
```

Требуются Python 3 и GNU objdump. Временные окна декодирования создаются только
в `runs/wave2/gap06` и удаляются. DLL читаются как файлы: без загрузки,
исполнения, эмуляции, injection, Windows/Detours или игровых процессов.
Legacy `verify_v7.py` сначала прочитан, но **не запускается**: он пишет файлы
в свой каталог и собирает дополнительные программы вне этой задачи.
Используется только прочитанный и закреплённый SHA-256 `pe_data.py` (`PE`);
его `mapped()` не вызывается. Изменяемые continuation-модули не проверяются.

`dispositions.json` закрепляет 47 исходных порядковых номеров и имён из
метрик H01, ожидаемые значения данных, источники и SHA-256. Поля архивных
PASS/общих счётчиков не используются как результат новой проверки.
`recheck.json` содержит отдельные новые вычисления и классификацию для каждого
из 47 пунктов; успешный exit code означает только успешные **поддерживаемые**
проверки, не повтор всех 209 пунктов.

Значения `disposition`:

- `freshly_rechecked`: заново вычисленный статический факт по закреплённым
  входам: хеши, полные строки/DJB2, дескрипторы, RTTI/484 исполняемых указателя
  для каждой из четырёх таблиц, их слот +78C, float32 и GNU byte/length для 162
  инструкций. GNU-агрегат пересекается с прежними 162 байтовыми проверками;
  его нельзя прибавлять как 162 новых пункта к общим 209.
- `model_only`: своя модульная арифметика литералов и ограниченная IEEE-754
  модель bias. Это не исполнение DLL, не проверка режима округления x87 и не
  полная эквивалентность. Связанные литералы/константы сверяются с файлами.
- `historical_only`: конкретный старый инструмент или исторический интервал
  не повторён. Собственный PE-разбор ресурса — дополнительный факт, **не**
  запуск pefile/LIEF. Для pefile/LIEF и Rizin байтовые входы доступны для
  отдельного нового повтора; для пяти точных VEX-блоков одних названий и длин
  недостаточно. Новые хеши до/после описывают только интервал этого повтора,
  не исторический аудит.
- `unresolved`: нельзя обоснованно отнести пункт к остальным категориям.
  Нулевой счётчик не означает отсутствие незакрытых gates; они перечислены
  отдельно, включая исторические проверки и исходный полный протокол.

`strict_old_protocol_repeated=false`, `all_209_repeated=false`,
`external_independent_audit=false` сохраняются. Источник этой границы —
закреплённый H01 ledger (`script_present=False`) и отсутствующий в трёх
цитируемых местах `verify_history_metrics_current.py`: handoff/continuation,
workspace/continuation и workspace/work/RAGEBOT_FINAL_v2/continuation.
Полного обзора репозитория/внешнего независимого аудита здесь нет.
