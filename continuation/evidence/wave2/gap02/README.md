Повтор одного адреса в разных архивных walks не является независимым наблюдением.
Категория перекрытия означает только арифметику смещения и ширины операнда;
она не означает доступ к полю порога или установленную принадлежность объекту.
Ни одна строка широкого списка автоматически не повышена до типизированного
потребителя T+68, в том числе строки из файлов со словами `target`/`chance`.

Четыре существующих `proof_spec.json` V7/V8/V9/V10 перечисляют соответственно

архивный manifest задаёт число `records`, оно совпадает с сохранённым JSON.
Это сверка перечня и чисел, **не повтор исторических протоколов**. Сохранённые
walks сами ограничены over-approximation обеих условных сторон; вызовы не
прослеживаются автоматически, аналитическая граница не доказывает полноту функции.
