# W9: распределение оставшихся направлений

Стартовая база: `82ede5e1ac90c393e7522afffc6f45f0faa7703e`. W8 остаётся принятой ограниченной базой; полная цель не достигнута.

[Точные назначения, владельцы, области записи и критерии](assignments.json). Все 19 текущих unresolved boundaries распределены между шестью исполнителями и координатором. Назначение не означает закрытие GAP.

| Владелец | Направление |
| --- | --- |
| `w9-selection` | Выбор цели, фильтры и первые положительные флаги |
| `w9-damage-geometry` | Урон, броня/пробитие и геометрия |
| `w9-angle-movement` | Углы, отдача, движение и остановка |
| `w9-history-shot` | История, память и учёт результата выстрела |
| `w9-lifecycle-message` | Сообщения, жизненный цикл данных, зарядка и DT/HS |
| `w9-queue-abi` | Очередь, внешние зависимости, ABI и исходный язык |

Координатор: общий реестр, межмодульные связи, H01/внешний аудит, интеграция, Makefile, полные проверки и независимое ревью фиксированного SHA.

Каждый исполнитель начинает с одного конкретного незакрытого участка, работает в отдельном worktree/BUILD и возвращает доказанный код либо точную границу исследования. Без запуска/загрузки/эмуляции оригинала, подключения к игре, вымышленных providers и обещаний полной реконструкции. PR только для просмотра, без merge/queue/auto-merge.
